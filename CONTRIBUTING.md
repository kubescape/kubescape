# Contributing

The Kubescape project manages this document in the central project repository.

Go to the [centralized CONTRIBUTING.md](https://github.com/kubescape/project-governance/blob/main/CONTRIBUTING.md)

## Issue assignment for this repository

The [contribution policy](.github/CONTRIBUTION_POLICY.md) describes the
issue triage, assignment and PR automation for `kubescape/kubescape`. It takes
effect on the rollout date configured by maintainers; existing PRs are exempt.

After activation, wait until a maintainer removes `status: needs-triage` before
requesting an assignment. Ask a maintainer to assign you to an available issue.
Self-assignment is not allowed; `/assign-me` is rejected. Maintainers must also
ask another maintainer to assign them. Use `/unassign-me` to release your work.
You may hold up to three active issue assignments. Begin work after assignment,
and link the issue in your PR with `Fixes #number` or `Refs #number` for partial work.

This repository-specific process changes the central guide's allowance for small
PRs without issues after rollout. Maintainers can handle small maintenance work
through the documented maintainer exemption.
